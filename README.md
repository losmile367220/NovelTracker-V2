# NovelTracker V2.3 Search

## 本版完成
- 右下角浮動搜尋按鈕
- 搜尋目前所在的「總覽／小說／短劇」頁面
- 上一個／下一個
- 顯示目前結果與總結果數
- 搜尋結果高亮
- Enter 前往下一個
- Shift + Enter 前往上一個
- Esc 關閉搜尋
- 手機版搜尋浮在底部導覽列上方
- 新增、編輯、刪除後若搜尋框仍開啟，會自動重新整理搜尋結果
- 切換頁面時會自動清除前一頁搜尋狀態
