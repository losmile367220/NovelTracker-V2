## 更新方式
將 ZIP 解壓後，全部覆蓋到 GitHub `NovelTracker-V2` Repository 根目錄，再 Commit。

若 V1 與 V2 使用不同 GitHub Pages 網址，瀏覽器的 localStorage 不會自動共用；後續接回 Google Sheets 後，可直接從雲端載入正式資料。
